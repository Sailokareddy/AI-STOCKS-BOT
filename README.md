# AI Stock Bot V3 — Gmail OAuth

1. In Google Cloud, create a Desktop app OAuth client.
2. Download the JSON file. Keep it private.
3. Rename it credentials.json and place it beside app.py.
4. Install: pip install -r requirements.txt
5. Run: streamlit run app.py
6. Click Connect Gmail and authorize your Google account.
7. Click Send test email.

The app requests only the Gmail send permission.
Do not paste or upload your OAuth client secret into chat.
